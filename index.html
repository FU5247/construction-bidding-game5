ゲームの遊び方・ルール

🎯 ゲームの目的

全ターンを生き残り、最も多くの資金（Y）を持っていた企業が勝利となります。資金がマイナスになると「破産」となり、実質脱落となります（他の企業の市場競争は最後まで進行します）。

🔄 ターンの流れ

  1. 景気決定： 抽選により「好景気」か「不景気」が決まります。数値設定で確率をカスタマイズ可能です。景気により採用・発注のコストが変動します。
  2. 入札フェイズ： 大・中・小いずれかの工事を選び、1Y単位で入札します。一番安い金額（最安値）を提示した1社のみが落札（受注）できます。同額の場合は抽選になります。
  3. 雇用フェイズ： 落札できた場合、工事に必要な人数を満たすように人を雇います。
  4. 清算： 獲得した入札額から、人件費を引いた額が資金に反映されます。

👷 雇用とコストについて

人数は 正社員:1人 / 発注・派遣:1人 として計算されます。

  • 👨‍💼 正社員（採用費:発注と同額 / 維持費: 30Y）： 一度雇うと解雇できません。採用時は発注と同じ額がかかりますが、以降は毎ターン固定費(30Y)のみがかかります。長期的に見るとコストパフォーマンスに優れます。
  • 👷 発注・派遣（好景気40Y / 不景気50Y）： そのターン限りの人員です。維持費はかかりませんが、毎回景気に合わせたコストがかかります。

🤖 CPUの戦略について

設定から各CPUの性格を変更できます。

  • 自律適応型： 正社員雇用と発注の両方を経験した勝者のデータを学習し、状況に応じて柔軟に使い分ける賢いAI。プレイヤーの隙（独占状態）を検知すると横取りしてくることもあります。
  • 完全外注特化： 正社員を雇わず、すべて派遣で賄う身軽な戦略。
  • 完全正社員特化： 積極的に正社員を雇い、固定費をかけても受注を狙う戦略。
